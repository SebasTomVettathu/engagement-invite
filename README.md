## 🚀 Deploy to GitHub Pages (Free Hosting + Shareable Link)

### Step 1 — Create a GitHub account
Go to [github.com](https://github.com) and sign up (free).

### Step 2 — Create a new repository
1. Click the **+** icon → **New repository**
2. Name it: `engagement-invite`
3. Set to **Public**
4. Click **Create repository**

### Step 3 — Upload the file
1. Click **Add file → Upload files**
2. Drag and drop `index.html` from this folder
3. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Go to **Settings** → **Pages** (left sidebar)
2. Under **Source**, select **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Click **Save**

### Step 5 — Get your shareable link
After ~1 minute your site will be live at:
```
https://<your-github-username>.github.io/engagement-invite/
```

Share this link on WhatsApp with family and friends! 🎉
